# Sahil Pahwa: portfolio site

Static site (HTML, CSS, JS). No build step. Live at https://connectsahilpahwa.github.io/sp/

## Files
- `index.html`: all content
- `styles.css`, `script.js`: design and behaviour
- `images/`: optimised photos, badges, logos and the social share card (`og-card.jpg`)

## Before you publish
Export your revised CV from Word as PDF and save it in the repo root as
`CV_Sahil_Pahwa_RPA_AgenticAI_13Yrs.pdf`. The Download CV buttons point to that name.
Delete the old `CV_Sahil_Pahwa_RPA_AgenticAI_12+Yrs.pdf` files.

## Update later
Edit the text in `index.html`. Project rows are `<details class="row">` blocks.
