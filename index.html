How I build agents

The pattern behind the Supplier Problem Assistant and the Onboarding & Offboarding Assistant.

  • Grounded. Retrieval over a vector database, so answers come from the client's own data and instructions.
  • Able to act. Typed tool and API calls through MCP into SAP, ServiceNow, SharePoint and other systems.
  • Controlled. Human approval for risky steps, security controls and exception handling.
  • Auditable. Every step is logged, so operations and risk teams can review it.
